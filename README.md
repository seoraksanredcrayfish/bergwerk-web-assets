# bergwerk-web-assets

베르크서울의 **공개 배너·웹 그래픽·사용 허락을 받은 리뷰 사진과 표시용 데이터**를 보관하는 저장소입니다.
공개된 모든 파일과 커밋 이력은 외부에서 열람할 수 있습니다. 이 README가 이 저장소의 작업·연결·보존 규칙 진입점입니다.

## 저장소 역할과 공개 범위

| 저장소 | 역할 | 공개 상태와 경계 |
| --- | --- | --- |
| [bergwerk-web-assets](https://github.com/seoraksanredcrayfish/bergwerk-web-assets) | 배너, 승인된 웹 그래픽, 리뷰 사진·피드, 사용 안내 | 공개. 영상·전체 홈페이지 코드·비공개 참고 자료는 넣지 않습니다. |
| bergwerk-storefront | 홈페이지 소스, 시안, 참고 자료와 아카이브 | 비공개 유지. 이 저장소 작업을 이유로 공개 전환하지 않습니다. |
| [bergwerk-media](https://github.com/seoraksanredcrayfish/bergwerk-media) | 자사 상품 영상 | 기존 영상용 저장소 유지. 배너 작업과 섞거나 기존 영상을 수정하지 않습니다. |

- 인증정보, 토큰, 비밀번호, 환경 파일, 고객 연락처·주문정보, 비공개 로그·문서를 올리지 않습니다.
- 홈페이지 전체 소스, 기존 아카이브, 비공개 Pinterest 보드·첨부 참고 이미지 원본은 공개 범위가 아닙니다.
- 자사 소유 또는 공개·상업적 사용 권한이 확인된 소재만 올립니다. 참고 이미지 열람이나 저장은 재사용 허락이 아닙니다.
- 공개 저장소라는 사실이 제3자에게 사진·그래픽의 사용권을 부여한다는 뜻은 아닙니다. 임의로 오픈 라이선스를 붙이지 않습니다.
- 읽기·조사 외 업로드, 교체, 삭제, 공개 범위 변경, 운영 적용은 대상과 범위가 승인된 작업에 한합니다.

## 기존 자산 보존과 버전 관리

- 기존 Cafe24 이미지, 기존 GitHub 자산, Figma 원본, 운영 HTML을 덮어쓰거나 삭제하지 않습니다.
- 원본을 복사해 보관하고, 현재 배너 4개는 원본 바이트 그대로 사용합니다. 불필요한 재압축·크롭·색상 변경을 하지 않습니다.
- 편집·최적화가 필요하면 원본과 구분되는 새 파일명으로 파생본을 만들고, 비율·색·선명도와 화면 크롭을 확인합니다.
- 이미 사용 중인 파일의 이름·경로를 바꾸거나 삭제하지 않습니다. 교체 소재는 새 이름으로 추가하고 승인된 화면의 주소만 바꿉니다.
- 이전 파일과 커밋은 유지합니다. 캐시 삭제, 이력 재작성, 강제 푸시로 정리하지 않습니다.
- 로컬 백업은 공개 저장소에 넣지 않습니다. 변경 전 원본·주소·커밋과 백업의 읽기/복원 가능 여부를 확인합니다.

## 리뷰 사진·상품 태그 규칙

상세 형식과 예시는 [reviews/README.md](reviews/README.md)에 있습니다. 상세 안내와 이 요약이 충돌하면 임의로 적용하지 말고 확인합니다.

- 사진 공개 사용 허락을 먼저 확인합니다. 개인정보·비공개 계정 사진·허락받지 않은 고객 사진을 올리지 않습니다.
- 승인된 사진을 `reviews/photos/`에 추가하고 `reviews/reviews.json`의 `items`에 등록합니다. 배열 순서가 표시 순서입니다.
- 한 항목의 필드는 `id`, `image`, `alt`, 선택 사항인 `instagramUrl`, 상품 태그 배열 `tags`입니다.
- `image`는 JSON 기준 상대 경로 또는 공개 HTTPS 이미지 주소입니다. `alt`는 실제 사진을 설명하고 후기·사용자를 지어내지 않습니다.
- `instagramUrl`은 실제 Instagram 게시물/릴스의 HTTPS 링크만 사용합니다. 비워 두면 클릭 링크 없이 표시됩니다. 링크 등록만으로 사진이 수집되거나 Instagram과 동기화되지 않습니다.
- 태그의 `name`은 실제 상품명, `url`은 확인된 실제 상품 페이지입니다. 좌표 `x`, `y`는 사진 왼쪽·위 기준 0~100 백분율입니다. 좌표를 생략하면 하단에 순서대로 배치됩니다.
- 태그가 없으면 `tags: []`로 둡니다. 상품명·상품번호·주소·태그 위치를 추측하지 않습니다.
- JSON 문법과 필드를 검증하고 커밋한 뒤 테스트 홈에서 실제 사진·순서·태그 위치·상품 링크를 확인합니다.
- 사진 0건일 때 등록 대기 시안이 표시될 수 있습니다. 예시나 대기 시안을 실제 고객 후기·사진으로 보고하지 않습니다.

리뷰 피드 주소: https://raw.githubusercontent.com/seoraksanredcrayfish/bergwerk-web-assets/main/reviews/reviews.json

리뷰 피드는 배너와 달리 `main`을 읽는 표시용 데이터입니다. 피드 커밋이 연결된 테스트 화면에 영향을 줄 수 있으므로 공개 내용과 JSON을 먼저 검증합니다. 운영 홈 연결은 별도 승인 대상입니다. 피드 갱신은 Cafe24 HTML 자동 배포와 다릅니다.

## 웹 그래픽·About 제작 경계

- 광산은 숨은 가치 발굴의 철학, 서울은 동시대적 감각, 동대문은 첫 발굴지입니다. 동대문을 탐색 범위의 경계로 축소하지 않습니다.
- 승인된 한·영 문구와 세릭·오픈와이와이 사례를 그래픽 작업 중 임의로 삭제하거나 다시 쓰지 않습니다.
- 레퍼런스는 미감 방향입니다. 사진 중심의 자료 조각, 넓은 여백, 연구 도판·작업 보드의 투박한 편집 감각을 참고하되 원본 이미지·레이아웃을 그대로 복사하지 않습니다.
- 광산 일러스트, 흑백 선 그래픽, 원석 연결도, 도매–베르크서울–고객 다이어그램은 확정 도안이 아닙니다. 광산을 대놓고 설명하는 장식으로 고정하지 않습니다.
- 현재 문구·폰트·기능을 보존하고 시안과 운영 자산을 구분합니다. 새 그래픽은 확인·승인 전 공개 업로드나 운영 적용을 하지 않습니다.
- 승인 없이 로고를 만들거나 기존 브랜드를 새 로고로 대체하지 않습니다. 글자 워드마크를 유지합니다.
- 폰트·외부 사진·아트·도표의 상업 사용 권한을 확인합니다. 비공개 Pinterest 자료를 이 공개 레포에 그대로 옮기지 않습니다.
