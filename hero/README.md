# 상단 배너(히어로)를 Git으로 추가하기

등록 목록: [hero.json](hero.json)

이미지·포스터: [images/](images/)

**운영 홈에 연결되어 있습니다.** 운영 홈 https://bergwerkseoul.com/ (같은 스킨이 https://bergwerk.kr/ 에도 나갑니다)의 Cafe24 skin2 `index.html` 히어로 스크립트가 이 저장소 `main`의 `hero.json`을 읽습니다. 테스트 홈 https://bergwerk.cafe24.com/skin-skin2/index_test.html 도 같은 목록을 읽지만 MAG001·`pin` 처리는 없고 JSON 순서 그대로 보입니다.

## 추가 방법

1. 승인된 새 이미지 또는 영상 포스터를 `hero/images/`에 새 파일명으로 업로드하고 커밋합니다. 이미 사용 중인 파일을 덮어쓰거나 삭제하지 않습니다.
2. 영상 본체는 `bergwerk-media-2` 저장소(예전 항목은 `bergwerk-media`)에 새 파일로 둡니다. 이 저장소에 영상을 복사하지 않습니다.
3. `hero.json`의 `items` 배열에 새 항목을 추가합니다. 이미지는 `type: "image"`, 영상은 `type: "video"`입니다. 현재 등록된 항목이 실제 사용 예시입니다.
4. 이미지·영상·포스터의 `src` 또는 `poster`는 **파일이 들어 있는 실제 커밋 SHA로 고정된 공개 HTTPS URL**(jsDelivr `gh/<저장소>@<SHA>/<경로>`)로 등록합니다. GitHub 파일 보기 주소가 아니라 실제 미디어 주소를 사용합니다.
5. JSON 문법, 공개 URL의 응답, 사용 권한을 확인하고 `main`에 커밋/푸시합니다. 운영 홈을 새로고침해 표시와 재생을 확인합니다. 목록 변경만으로는 Cafe24 HTML을 다시 저장할 필요가 없습니다.

**파일만 업로드하고 목록에 등록하지 않으면 표시되지 않습니다.** GitHub raw 캐시 때문에 푸시 후 반영까지 몇 분 걸릴 수 있고 즉시 반영을 보장하지 않습니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 다른 항목과 겹치지 않는 고유 ID |
| `type` | `image` 또는 `video` |
| `src` | 커밋 고정된 실제 이미지 또는 MP4 주소 |
| `poster` | 영상의 커밋 고정된 포스터 이미지 주소. 영상에는 필수 |
| `alt` | 실제 소재를 설명하는 대체 텍스트 |
| `href` | 검증한 클릭 목적지. 목적지가 없으면 빈 문자열로 유지. 쇼핑몰 안 페이지는 `/product/list.html?cate_no=164`처럼 `/`로 시작하는 상대경로를 씁니다. 손님이 들어온 도메인(bergwerkseoul.com 또는 bergwerk.kr) 그대로 이동해 로그인이 유지됩니다. 두 도메인은 쿠키가 따로라서 절대주소로 다른 도메인을 가리키면 로그인이 풀립니다. 외부 주소는 `https://`만 허용됩니다 |
| `pin` | 선택. `true`면 섞이지 않고 맨 앞(MAG001보다 앞)에 고정합니다. 기간이 끝나면 `pin`을 지우거나 항목을 목록에서 뺍니다 |

루트 `version`은 현재 형식 `1`입니다. 고객 정보, 인증정보, 비공개 자료, 홈페이지 소스는 등록하지 않습니다. 상품명·상품번호·카테고리·링크를 추측하지 않습니다.

## 표시와 동작

- 2:3 비율로 표시합니다. 2:3 원본을 권장하며 다른 비율의 소재는 가장자리가 잘릴 수 있습니다.
- PC는 왼쪽 슬라이더 1장 + 오른쪽 고정 이미지(`images/hero-right.jpg`)입니다. 오른쪽과 같은 사진인 `style-01`은 PC 슬라이더에서 빠집니다. 모바일은 화면 폭에 맞춘 1장입니다.
- **순서를 섞지 않습니다.** 순서는 `pin: true` 항목(JSON 순서) → MAG001(매거진 #001 표지, 운영 HTML 스크립트에 고정) → 나머지 항목(JSON 순서)입니다. 이전/다음 버튼과 스와이프는 이 순서를 따릅니다.
- PC에서는 2:3 슬라이드가 화면보다 길어서 첫 화면에 위쪽 약 62~73%만 보입니다(화면 비율·브라우저 바에 따라 다름). 글자나 핵심 소재는 슬라이드 높이 60% 위쪽에 둡니다.
- 영상은 무음·반복 재생하며 보이지 않는 영상은 정지합니다. 재생/정지 글자 대신 아이콘을 사용합니다. 동작 줄이기 설정에서는 자동 재생하지 않습니다.
- `href`를 비우면 클릭 이동 없이 표시합니다.
- 운영 `index.html` 안의 대체 목록(`bgw-hero-fallback`)을 먼저 그린 뒤 `main`의 목록을 받으면 다시 그립니다. 원격 요청에 실패하거나 목록이 유효하지 않으면 대체 목록을 그대로 씁니다. 첫 방문에 순서가 바뀌어 보이지 않게 하려면 고정할 항목을 대체 목록에도 넣어야 하며, 이는 HTML 수정이라 별도 승인이 필요합니다.

## 복구와 경계

목록 변경은 해당 JSON을 직전 정상 커밋의 내용으로 되돌려 새 커밋합니다. 이력 재작성·강제 푸시·기존 자산 삭제는 하지 않습니다. 히어로 스크립트·대체 목록 등 운영 HTML 수정은 전체 백업 후 별도 승인 작업으로 합니다.

이 목록의 갱신은 **표시 데이터 갱신**입니다. Cafe24 HTML 배포나 Figma 수정이 자동으로 이루어진다는 뜻이 아닙니다.
