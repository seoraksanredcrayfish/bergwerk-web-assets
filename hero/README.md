# 상단 배너를 Git으로 추가하기

등록 목록: [hero.json](hero.json)

이미지·포스터: [images/](images/)

연결 대상은 **테스트 홈** https://bergwerk.cafe24.com/skin-skin2/index_test.html 입니다. 운영 홈은 연결하지 않습니다.

## 추가 방법

1. 승인된 새 이미지 또는 영상 포스터를 `hero/images/`에 새 파일명으로 업로드하고 커밋합니다. 이미 사용 중인 파일을 덮어쓰거나 삭제하지 않습니다.
2. 영상 본체는 기존 `bergwerk-media` 저장소에 둡니다. 이 저장소에 영상을 복사하지 않습니다.
3. `hero.json`의 `items` 배열에 새 항목을 추가합니다. 이미지는 `type: "image"`, 영상은 `type: "video"`입니다. 현재 등록된 3개 항목이 실제 사용 예시입니다.
4. 이미지·영상·포스터의 `src` 또는 `poster`는 **파일이 들어 있는 실제 커밋 SHA로 고정된 공개 HTTPS URL**로 등록합니다. GitHub 파일 보기 주소가 아니라 실제 미디어 주소를 사용합니다.
5. JSON 문법, 공개 URL의 응답, 사용 권한을 확인하고 `main`에 커밋/푸시합니다. 테스트 홈을 새로고침해 표시와 재생을 확인합니다. Cafe24 HTML을 다시 저장할 필요는 없습니다.

**파일만 업로드하고 목록에 등록하지 않으면 표시되지 않습니다.** GitHub·CDN 캐시나 네트워크 상태 때문에 즉시 반영을 보장하지 않습니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 다른 항목과 겹치지 않는 고유 ID |
| `type` | `image` 또는 `video` |
| `src` | 커밋 고정된 실제 이미지 또는 MP4 주소 |
| `poster` | 영상의 커밋 고정된 포스터 이미지 주소. 영상에는 필수 |
| `alt` | 실제 소재를 설명하는 대체 텍스트 |
| `href` | 검증한 클릭 목적지. 목적지가 없으면 빈 문자열로 유지 |

루트 `version`은 현재 형식 `1`입니다. 고객 정보, 인증정보, 비공개 자료, 홈페이지 소스는 등록하지 않습니다. 상품명·상품번호·카테고리·링크를 추측하지 않습니다.

## 표시와 동작

- 2:3 비율로 표시합니다. 2:3 원본을 권장하며 다른 비율의 소재는 가장자리가 잘릴 수 있습니다.
- PC는 2장 나란히, 모바일은 화면 폭에 맞춘 1장입니다.
- 접속·새로고침 때 순서를 섞습니다. 같은 접속 내에서 이전/다음 버튼과 스와이프는 그 순서를 유지합니다. 랜덤이므로 동일한 순서가 다시 나올 수도 있습니다.
- 영상은 무음·반복 재생하며 보이지 않는 영상은 정지합니다. 재생/정지 글자 대신 아이콘을 사용합니다. 동작 줄이기 설정에서는 자동 재생하지 않습니다.
- `href`를 비우면 클릭 이동 없이 표시합니다. 현재 새 이미지와 FW02 영상은 이동 링크를 비워 두었습니다.
- 표시용 목록은 `main`을 읽습니다. 원격 요청에 실패하거나 목록이 유효하지 않으면 테스트 HTML에 포함된 초기 3개 배너로 안전하게 대체합니다.

## 복구와 경계

목록 변경은 해당 JSON을 직전 정상 커밋의 내용으로 되돌려 새 커밋합니다. 이력 재작성·강제 푸시·기존 자산 삭제는 하지 않습니다. 테스트 홈의 슬라이드 기능 자체를 되돌리는 것은 비공개 HTML 백업을 이용한 별도 승인 작업입니다.

이 목록의 갱신은 **표시 데이터 갱신**입니다. Cafe24 HTML 배포, Figma 수정, 운영 홈 전환이 자동으로 이루어진다는 뜻이 아닙니다. 운영 적용은 별도 승인이 필요합니다.
